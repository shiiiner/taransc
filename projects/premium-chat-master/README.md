# Premium Chat Master — After Effects (30s)

قالب مادر موشن‌گرافیک چت برای تولید محتوای داروی برند premium. خروجی فایل اسکریپت JSX برای After Effects است.

## مشخصات
- ابعاد: 1080 × 1920 (عمودی استوری/ریلز/دایرکت)
- مدت: ۳۰ ثانیه
- نرم‌افزار: After Effects (اسکریپت JSX، سازگار با ExtendScript ES3)
- سبک: Minimal / Premium — بدون کپی کردن کامل رابط اینستاگرام

## فایل‌ها
- `Premium_Chat_Master_30s.jsx` — اسکریپت سازنده پروژه
- `README.md` — این فایل

## نحوه اجرا
1. After Effects را باز کنید.
2. From menu: **File > Scripts > Run Script File...**
3. فایل `Premium_Chat_Master_30s.jsx` را انتخاب کنید و اجرا کنید.
4. کامپوزیشن `PREMIUM_CHAT_MASTER_30S` به مدت ۳۰ ثانیه ساخته می‌شود.
5. اگر قبلاً کامپوزیشن ناقصی ساخته شده است، آن را حذف کنید و دوباره اسکریپت را اجرا کنید.

## شخصی‌سازی (قالب مادر)
در ابتدای فایل JSX، بخش `SETTINGS` وجود دارد. فقط اینجا تغییر دهید، کد انیمیشن را دست نزنید:

```js
var SETTINGS = {
    // متن‌ها (مکالمه mẫu — جایگزین متن واقعی برند شوید)
    messages: [
        { sender: "user",    text: "سلام، این محصول برای چه نوع پوستی مناسبه؟", time: 4.0, end: 8.5, check: 8.7, bubbleY: 800 },
        { sender: "brand",   text: "سلام! این محصول برای پوست‌های چرب و مختلط طراحی شده...", time: 14.0, end: 20.5, bubbleY: 1080 },
        { sender: "user",    text: "چطور باید ازش استفاده کنم؟", time: 21.0, end: 23.5, check: 23.7, bubbleY: 1360 },
        { sender: "brand",   text: "شبانه قبل از خواب، روی پوست تمیز و خشک بگذارید...", time: 25.0, end: 29.0, bubbleY: 1620 }
    ],
    // رنگ‌ها (RGB ۰ تا ۱)
    colorBrand: [0.22, 0.78, 0.58], // رنگprimer برند
    colorBg: [0.039, 0.043, 0.058],
    // ...
    logoText: "Z",        // مونوگرام لوگو
    handle: "@brand.handle" // نشان‌نامه
};
```

- `time`: شروع تایپ پیام (ثانیه)
- `end`: پایان تایپ پیام (ثانیه)
- `check`: زمان ظاهر شدن علامت تایید (فقط پیام‌های کاربر)
- `bubbleY`: موقعیت عمودی پیام در صفحه چت (پیکسل)

## نکته مهم: متن فارسی
After Effects ممکن است حروف فارسی را disconnected یا به صورت LTR نشان دهد. برای اصلاح:
1. فونت را به فونت‌ای با پشتیبانی فارسی تغییر دهید (مثلاً `Tahoma`، `Segoe UI`، `Vazirmatn`) در بخش `fontMain` / `fontBold`.
2. در After Effects، paragraph direction Text layerها را به **Right-to-Left** تنظیم کنید.
