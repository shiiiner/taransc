# ویرایشگر محلی زیرنویس فارسی

برنامهٔ مستقل Python با رابط مرورگری برای وارد کردن SRT کلمه‌ای و جمله‌ای، بازبینی روی ویدئو یا صوت و خروجی Caption Studio. نیازی به API، کلید Gemini، اینترنت یا نصب کتابخانهٔ جانبی ندارد. خود فایل صوت/ویدئو در مرورگر باقی می‌ماند. متن SRT برای پردازش به سرور محلی Python فرستاده می‌شود.

## اجرا

Python 3.9 یا جدیدتر را نصب کنید. در ترمینال از پوشه اصلی مخزن اجرا کنید:

```bash
python python_caption_editor/app.py
```

در ویندوز ممکن است به جای `python` لازم باشد `py` بنویسید. سپس آدرس `http://127.0.0.1:8765` را در مرورگر باز کنید و تا پایان کار ترمینال را باز نگه دارید. برای بستن Ctrl+C بزنید. اگر پورت مشغول است: `python python_caption_editor/app.py --port 8766`. به طور پیش‌فرض فقط دستگاه خودتان می‌تواند به برنامه وصل شود.

## روش کار

1. در Google AI Studio دو خروجی SRT بگیرید: اولی **دقیقاً یک کلمه در هر بلوک با شروع و پایان مستقل** و دومی جمله‌ای. آن‌ها را UTF-8 ذخیره کنید. برنامه زمان‌بندی تولید نمی‌کند و درستی خروجی مدل را تضمین نمی‌کند.
2. فایل صوت یا ویدئو و SRT کلمه‌ای را انتخاب کنید؛ SRT جمله‌ای اختیاری است. بدون آن، گروه‌های اولیه هفت‌کلمه‌ای ساخته می‌شوند.
3. پخش را بررسی کنید. متن، زمان شروع و پایان هر کلمه قابل تغییر است؛ ▶ کلمه را پخش می‌کند، ✂ جمله را بعد از همان کلمه تقسیم می‌کند و «ادغام با بعدی» مرز بین دو جمله را حذف می‌کند. می‌توانید کلمه را حذف کنید یا با وارد کردن زمان واقعی، به انتهای جمله اضافه کنید. برای جابه‌جایی یک مرز، جمله را در محل جدید تقسیم و بخش دلخواه را با جمله بعدی ادغام کنید.
4. برای خروجی، خطاهای بالای صفحه را برطرف کنید. JSON برای Caption Studio است؛ خروجی‌های جداگانه SRT جمله‌ای و کلمه‌ای نیز قابل دانلودند. فایل رسانه و SRTها پس از بستن صفحه باید مجدداً انتخاب شوند؛ ذخیره و بازیابی کل پروژه هنوز پشتیبانی نمی‌شود.

## محدودیت‌های مهم

- هم‌ترازی SRT جمله‌ای بر اساس شباهت و ترتیب متن است، نه هم‌ترازی دقیق صوتی. کلمات تطبیق‌نیافته جدا نگه داشته می‌شوند، اختلاف‌ها و کلمات بدون زمان هشدار دارند و باید دستی بررسی شوند. متن مرجع خودکار جایگزین نمی‌شود. اعداد، تکرارها و اختلاف در تعداد کلمات ممکن است هم‌ترازی را جابه‌جا کند.
- حد کلمه/نویسه یک راهنمای قابل تنظیم است نه استاندارد قطعی یا تضمین تک‌خطی بودن. پیش‌نمایش با فونت مرورگر است و خط‌بندی واقعی به فونت، اندازه، ابعاد کامپوزیشن و تنظیمات Caption Studio بستگی دارد. Caption Studio ممکن است متن را کوچک یا بسته به تنظیمات خودش بازچینی کند.
- JSON جمله‌ها را تک‌خطی ذخیره می‌کند و زمان هر کلمه را حفظ می‌کند. در پنل Caption Studio حالت کلمه‌به‌کلمه را انتخاب کنید؛ زمان‌ها از ابتدای کامپوزیشن هستند و باید با مکان ویدئو هم‌خوان باشند. تقسیم خودکار جمله، حداقل مدت، نگه‌داشتن بعد از جمله و جابه‌جایی زمان در پنل می‌توانند نتیجه را تغییر دهند.
- پشتیبانی MP4، MOV و فرمت‌های دیگر به مرورگر و کدک فایل وابسته است. اگر فایل پخش نشد آن را به MP4 با H.264/AAC یا WAV تبدیل کنید. استخراج صوت یا شکل موج در این ابزار انجام نمی‌شود.
- تست خواننده JSON با بخشی از کد Caption Studio انجام شده است، اما اجرای واقعی در After Effects و دقت زمان‌بندی باید با پروژه و صدای شما تست شود.

اجرای تست‌ها:

```bash
python -m unittest discover -s python_caption_editor/tests -v
```

## ساخت فایل اجرایی ویندوز

PyInstaller برای ساخت نسخه ویندوز باید روی **ویندوز** اجرا شود. فایل ساخته‌شده برای اجرای عادی به نصب Python نیاز ندارد، ولی همچنان از مرورگر نصب‌شده روی ویندوز استفاده می‌کند. به دلیل نبود امضای دیجیتال، ممکن است Windows SmartScreen درباره فایل هشدار دهد.

برای ساخت روی یک کامپیوتر ویندوز ۶۴ بیتی:

1. Python 3.12 را نصب کنید؛ برای نصب PyInstaller در زمان ساخت اتصال اینترنت لازم است.
2. فایل `python_caption_editor/build_windows.bat` را اجرا کنید. این فایل تست‌ها را اجرا و سپس برنامه را می‌سازد.
3. فایل `dist/PersianCaptionEditor.exe` را به سیستم مقصد منتقل کنید. اجرای آن نیازی به انتقال بقیه پروژه یا نصب Python ندارد.
4. با دوبار کلیک برنامه باز می‌شود و مرورگر پیش‌فرض را باز می‌کند. پنجره سیاه برنامه را هنگام کار باز نگه دارید؛ با بستن آن ویرایشگر متوقف می‌شود. اگر مرورگر باز نشد، آدرس نوشته‌شده در پنجره را دستی باز کنید. اگر پورت ۸۷۶۵ اشغال باشد، برنامه شروع نمی‌شود؛ نسخه قبلی را ببندید و دوباره اجرا کنید.

همچنین GitHub Actions با workflow به نام **Build Windows caption editor** نسخه Windows را می‌سازد و فایل آن را در بخش Artifacts با نام `PersianCaptionEditor-Windows` قرار می‌دهد، مشروط به اینکه این تغییرات به GitHub فرستاده شوند و اجرای workflow موفق باشد. پیکربندی workflow به تنهایی به معنی ساخته شدن فایل نیست.
